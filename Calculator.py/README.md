# 🧮 Python Calculator

A simple command-line calculator built in Python as part of my **100 Days of Code: The Complete Python Pro Bootcamp** journey.

## 📌 About the Project

This calculator performs basic arithmetic operations and allows the user to continue calculating using the previous result.

The available operations are:

- Addition `+`
- Subtraction `-`
- Multiplication `*`
- Division `/`

The calculator also uses a dictionary to map operators to their corresponding functions.

## ✨ Features

- Basic arithmetic operations
- Continuous calculations using the previous result
- Option to start a new calculation
- User input validation for operations
- Command-line interface
- ASCII calculator logo

## 🧠 Concepts Practiced

This project helped me practice:

- Functions
- Parameters and arguments
- Return values
- Dictionaries
- Function references
- `while` loops
- `if / elif / else`
- User input
- Floating-point numbers
- Python modules and imports

The arithmetic operations are separated into individual functions, such as `add()`, `subtract()`, `multiply()`, and `divide()`.

## 🛠️ Technologies

- **Python 3**
- Python `art` module/file for the calculator logo

## ▶️ How to Run

Make sure Python 3 is installed on your system.

Run the calculator from the terminal:

```bash
python main.py
```

## 📷 Example

```text
Enter the first number: 10

+
-
*
/
Pick an operation: +

What's the next number: 5

10.0 + 5.0 = 15.0

Type 'y' to continue calculating with 15.0,
or type 'n' to start a new calculation: y
```
