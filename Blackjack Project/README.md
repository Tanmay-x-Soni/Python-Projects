# 🃏 Blackjack Game

A command-line Blackjack game built in Python as part of my **100 Days of Code: The Complete Python Pro Bootcamp** journey.

## 🎮 About the Game

This is a simple Blackjack game where the player plays against the computer.

The player starts with two cards and can choose to:
- Draw another card (`y`)
- Pass (`n`)

The computer automatically draws cards until its score reaches **16 or higher**.

The game then compares both scores to determine the winner.

## ✨ Features

- Random card generation
- Player and computer hands
- Blackjack detection
- Player bust detection
- Computer bust detection
- Ace handling (`11` → `1` when required)
- Win, lose, and draw conditions
- Replay option
- Command-line interface
- ASCII Blackjack logo
