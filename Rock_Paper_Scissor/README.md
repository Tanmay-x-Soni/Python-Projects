# Rock Paper Scissors

A simple **Rock Paper Scissors** game built with Python.

## About

This is a beginner Python project where the user plays Rock Paper Scissors against the computer.

The computer randomly selects one of the three choices, and the program determines the winner based on the game rules.

## How It Works

- The user chooses **Rock**, **Paper**, or **Scissors**.
- The computer randomly chooses one of the three options.
- The program compares both choices.
- The winner is displayed.

### Game Rules

| Player | Computer | Result |
|---|---|---|
| Rock | Scissors | Player wins |
| Paper | Rock | Player wins |
| Scissors | Paper | Player wins |
| Same choice | Same choice | Draw |
